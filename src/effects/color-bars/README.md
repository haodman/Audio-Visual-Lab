# 交错色条与弹跳文字（colorBars）

本文件夹只对应工作台的「交错色条」功能。入口为 `music-fx-lab.html?effect=colorBars`。

| 文件 | 用途 |
| --- | --- |
| `effect.js` | 1–3 张照片构图、独立取色、卡点色条、弹跳文字及选图控件 |
| `assets/orange.jpg` | 默认第 1 张：橘子 |
| `assets/portrait.jpg` | 默认第 2 张：人像 |
| `assets/pool.jpg` | 默认第 3 张：泳池 |
| `fonts/Silkscreen-Regular.ttf` | 弹跳文字字体 |
| `fonts/Silkscreen-OFL.txt` | SIL Open Font License；发布包须保留 |

## 构图与互动

- 输出 540×960（9:16）；照片宽度默认 58%，可调 44–68%。
- 单图高度为画面 72%，上下居中；双图、三图的整列高度为 91%。
- 整列照片四个外角与工作台预览框保持相同显示半径；内部分界无缝。圆角直接绘入 Canvas，视频导出一致。
- 素材区选择 1 / 2 / 3 张，连续点击依次填图；点击编号缩略图可指定替换任一位置。支持一次上传 1–3 张和逐张上传替换。
- 自定义文字按空格、斜线或逗号分段，每段最多六字符；文字向上弹起并保持在画面内。

## 颜色与节奏

- 每张照片从当前裁切区域独立采样，在 OKLab 空间聚类。取面积最大的主色，再保留有区分的鲜明强调色，最多四色。颜色不足时复用已有色，不凭空补色。
- 背景固定浅暖灰 `#EEEDE7` 与固定淡纸纹，文字固定深绿 `#2B362F`；背景不随换图或节拍改变。
- 直接使用原 WebAudio DSP 分析的拍点；按拍点附近 RMS 强度同时伸出 1–3 条，也可固定条数，下一拍换侧。静音不触发；不使用 Beat This!。
- 完整阈值、采样与条数规则见仓库根 README 的「交错色条：照片选择、取色与节奏规则」。

## 资源来源与集成

示例照片来自用户提供的 MDP 视效素材库「色彩移动特效 / 输出示例 / 1999-Silkscreen / project.json」，仅缩小为最长边 1080 的 JPEG。没有导入旧歌词、歌曲或 Beat This! 拍点。

取色与完整伸缩曲线适配自 `color-motion-effects` 1.0.0。共享控件与效果注册在 `src/app.js`，结构样式在 `src/app.html`。运行 `python3 src/build.py` 将本目录的代码、照片与字体打包进两个根 HTML。不要手改生成文件。

源码仓库 `haodman/Audio-Visual-Lab` 与网站仓库 `haodman/haodman.com` 分开；发布需同步构建后的 HTML、字体授权及实际引用的音乐资源至网站的 `audio-visual-lab/`，并检查线上页面。
