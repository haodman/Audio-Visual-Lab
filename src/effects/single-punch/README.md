# 单图方块打孔 · singlePunch

独立于既有上下「图形镂空」`punchSymbols`。当前版本只用正方形，不再提供其他形状或照片碎片提取。用户确认的规则是：**每拍出现一个方块，位置错落分布；全部出现后，每两拍重新排布一次。**

## 两段节奏

1. 铺开阶段：每个有效音频拍点只新增一个不透明正方形，100ms 快速落位。没有成批同时出现或慢淡入。
2. 铺满阶段：从最后一个出场拍点开始计数，第二拍第一次换位，随后每两拍整体重新排布。数量、大小和每个方块的颜色保留，位置在拍点直接切换并轻微落位；拍间微飘，暂停定格。

复用共享 `S.analysis.beats`，在每个网格拍点前后 70ms 内寻找 PCM 短时能量上升，按 5ms 分辨率对齐附近起音。用对齐点前 15ms 至后 65ms 的多声道 RMS 排除静音。绝对 RMS 不足 0.0025，或低于本曲 82% 分位 RMS 的 7.5%，不触发。重排相位按原分析拍点编号计算，不因静音跳过后变成任意定时器。使用现有 WebAudio DSP，没有新增节拍模型。

静音、无音频或未分析完成时不伪造动画。换图、换曲、重新进入及「重新铺开」重置；向前 seek 可直接还原该时刻进度和排布，向后 seek/歌曲循环从新位置重新铺开。

## 两套配色严格分离

- **照片取色（默认）**：只读取当前可见照片的真实像素。颜色聚类的平均值只用于寻找代表像素，最终用的是实际像素 RGB；按颜色差异与出现频率选最多 8 色。不生成补色、不改饱和度或明暗，也不加白黑颗粒或半透明色层。照片只有少量颜色时复用这些颜色。无法读取照片像素时不补入外部色，提示换本地图片或主动选择撞色模式。
- **和谐撞色**：全部来自独立设计的 8 色方案，提供柠檬紫蓝、珊瑚青橙、电光糖果；不会混入照片取色。换图不会改变这一色板。

同一构图循环使用选定色板的所有颜色；重排不改色。方块为清晰、不透明的纯色正方形，人物自然遮挡沿用共享 MODNet，轮廓交界的合成和抗锯齿不构成额外配色来源。

## 已获认可的细节：人物主体保护

方块随拍点出现、铺满和隔拍重排时，人物保持在画面前景，方块经过人物轮廓时由人物自然遮挡。排布也优先使用低细节区域，并对视觉中心作避让，让照片中的表情、衣着和姿态保持清晰，彩色几何元素形成背景节奏与前后层次。

此效果复用项目已有的 MODNet 高清人像结果，在方块之后合成人物层；默认「主体留白」为 1，因此每次重排仍保留同样的前后关系。完整遮挡在高清分割结果就绪且主体留白保持默认值时生效。

2026-09-21 本地审片中，用户明确认可这一细节：“没有遮挡到人物”。已将其列为本功能汇报的重点和后续迭代需要保留的验收项。正式功能汇报见 [REPORT.md](REPORT.md)。

## 参数与入口

`music-fx-lab.html?effect=singlePunch`，可加 `&photo=海边粉衣双人`。共享抽屉提供配色来源、撞色方案、方块疏密、方块大小、轻飘幅度、主体留白；没有形状、物体提取或混合配色控件。

「看铺满效果」立即显示完整构图，并从当前拍点计数，隔拍重排；「重新铺开」恢复每拍一个的出场；「换个排布」手动换构图并保留音乐时间原点。常规默认仍先铺开再重排。图片和几何分析只在换图时计算，排布只在重排事件时生成。横图沿用主程序适配，视频以进入效果时的单帧为基础；主验收范围是照片。

## 文件和验证

`effect.js` 由 `src/build.py` 内嵌到两个 HTML 入口。无需新增素材或依赖。原有 15 秒带手机 UI 的导出器不改动；本地审片可调用既有 `MFX_EXPORT(24)` 录制更长片段，包含两段行为。

```sh
node --check src/app.js
node --check src/effects/single-punch/effect.js
python3 src/build.py
PUNCH_URL=http://127.0.0.1:8891/music-fx-lab.html node src/effects/single-punch/tests/browser.cjs
```

测试需要 Playwright 和 Chrome，可用 `PLAYWRIGHT_PATH`、`CHROME_PATH` 指定。验证实际像素取色、独立撞色色板、一拍一个、邻近起音对齐、铺满后仅偶数拍重排、颜色/数量保持、静音/暂停、上传/抽屉/旧效果回归及视频导出。时序误差断言只针对已知起音的测试音频，不代表任意真实歌曲的节拍识别准确率。
