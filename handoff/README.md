# Audio Visual Lab handoff pack

Recommended reading order:

1. `CODEX_START.md` — prompt and first commands for a new Codex task.
2. `PROJECT_STATE.md` — current product, effects, media, matting, and deployment state.
3. `DESIGN_DECISIONS.md` — accepted and rejected UX/effect decisions.
4. `QA_CHECKLIST.md` — local and public verification checklist.
5. Root `AGENTS.md` — rules Codex automatically receives when working in the repository.
6. Root `README.md`, `TECH-CAPABILITIES.md`, and `design-qa.md` — implementation reference.

The ZIP version of this pack intentionally does not include source code, music, or user media. Clone the private GitHub repository after the owner grants access; this keeps the package small and avoids stale duplicate code.
